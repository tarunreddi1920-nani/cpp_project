Movie Ticket Booking System in C++
Project Overview
This is a beginner-level, menu-driven C++ console application that simulates a basic movie ticket booking process.

Features in Version 1
Display three available movies.
Show movie IDs, genres, and ticket prices.
Select a movie and enter the number of tickets.
Calculate and display the total ticket cost.
Validate the movie selection and ticket quantity.
Return to the menu until the user chooses Exit.
C++ Concepts Used
Variables and input/output
Arrays
Classes and objects
Constructors
Functions
Loops
If-else statements
Switch statements
How to Run
Compile main.cpp with a C++ compiler.

Example using g++ in the VS Code terminal:

g++ main.cpp -o movie_booking
./movie_booking
Current Limitations
This version displays a booking summary only. It does not yet reserve actual seats, process payments, or save booking details.
