🎬 Movie Ticket Booking System

A beginner-friendly C++ console application that simulates a movie ticket booking process.

📌 Project Overview

This project allows users to view available movies, select a movie, enter the number of tickets, and calculate the total ticket price.

✨ Features

- View available movies
- Display movie names, genres, and prices
- Select a movie to book
- Enter the number of tickets
- Calculate the total amount
- Validate user choices
- Exit the application

🛠️ Technologies Used

- Programming Language: C++
- Concepts: Arrays, Classes and Objects, Constructors, Functions, Loops, If-Else, Switch Statements

▶️ How to Run

Compile the program using a C++ compiler:

g++ main.cpp -o movie_booking
./movie_booking
